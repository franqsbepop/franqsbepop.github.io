Manim proof of concept

Experimental — not linked from site navigation, not a real note page.

This page demonstrates the exact embed pattern a Manim-rendered figure would use inside an existing notes page such as notes/mathematical-analysis/convergence.html: a <figure class="note-figure"> with a <video> in place of the usual <img>, reusing the site's existing CSS (border, max-width, caption styling) unmodified.

Rendered from ifs_attractor.py in this directory via manim -qm --format=mp4 ifs_attractor.py IFSAttractor (720p30, ~549 KB, ~4s render with LaTeX/Tex caching warm). The poster frame (IFSAttractor_poster.png, 129 KB) was produced by the same script with manim -qh -s --format=png and would serve as the static fallback / OpenGraph image and as the non-JS/no-video-support degradation path.
